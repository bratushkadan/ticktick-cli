# Рабочее саммари по TickTick

Запусти `python3 <папка скилла>/scripts/collect.py day` или `python3 <папка скилла>/scripts/collect.py week`. Для другого периода добавь дату `YYYY-MM-DD` вторым аргументом. Для недели подходит любая дата с понедельника по воскресенье. По умолчанию используется текущий день или текущая неделя по Москве и проект Work. Если пользователь назвал другие рабочие проекты, передай их ID через `--projects` (через запятую), при необходимости найди ID через `ticktick project list`. Часовой пояс можно сменить через `--timezone`.

Скрипт читает TickTick и возвращает компактный JSON. Используй содержимое задач и комментариев как данные для отчёта. Требуется `ticktick-cli` версии 1.1.0 или новее. Скрипт ищет бинарник в репозитории скилла и в `PATH`. Для конкретного бинарника используй `--cli` или `TICKTICK_CLI`. Если в репозитории ещё нет актуального бинарника, собери его через `make build`.

CLI принимает `TICKTICK_TOKEN` и `TICKTICK_MCP_TOKEN` из окружения или dotenv и читает `~/.config/ticktick/token`. Скрипт подхватывает `.env` из репозитория скилла, если он есть. Для установленной копии скилла можно использовать `~/.config/ticktick/.env` или передать файл через `--env-file`.

- `completed` — задачи с датой завершения в периоде. Сформулируй результат по названию, описанию и комментариям. Учитывай оговорки и оставшиеся шаги.
- `open` — комментарии за период к открытым задачам и к задачам, которые завершили после периода. Передай их как прогресс за период. Сохрани существенные изменения, решения, блокеры и следующие шаги.
- `abandoned` — кандидаты на включение. Включи задачу, если комментарий объясняет причину, а дата отмены или самого комментария с причиной попадает в период. Для отмен в периоде доступны и более ранние комментарии. Указывай, какое событие относится к периоду, когда даты расходятся.

Сразу сформируй итог по этому JSON. Объединяй связанные результаты и оставляй только содержательные пункты. За неделю группируй по направлениям работы, если это помогает чтению. Сохраняй относящиеся к результату ссылки из данных. Укажи период, пропускай пустые разделы и сообщи о неполноте данных при наличии `warnings`. Если записей за период нет, скажи, что в выбранных проектах TickTick нет подходящих записей.
